How I built this

An official citation
can still be wrong.

A source can be genuine and relevant, but no longer be the rule in force. This product checks both relevance and regulatory validity.

Output
A traceable answer or an evidence-safe fallback.

Keep history

Current and historical research are different jobs.

Current question

“What are RBI’s rules on X?”

Use evidence that is active or amended and eligible now.

Historical question

“What were RBI’s rules on X in 2023?”

Prior material can be examined in the context in which it applied.

Product decisions

The choices behind the system.

Decision 01

Validity beats similarity

A lower-similarity current source outranks a highly similar withdrawn source for a current-guidance question.

Decision 02

Keep historical documents

Withdrawn regulations are retained because historical questions still need time-appropriate evidence.

Decision 03

Unknown does not mean current

When authority cannot be established, the product exposes that uncertainty instead of silently elevating the source.

Decision 04

Evidence before generation

Lifecycle eligibility is resolved before answer generation so the generator is not asked to choose between current and obsolete material.

How the product evolved

Each failure changed the next version.

  1. V0

    Document RAG

    Relevant documents could be retrieved, but relationships were weak.

  2. V1

    Knowledge Graph RAG

    Added relationships between regulations, concepts and entities.

  3. V2

    Validity-aware retrieval

    Added lifecycle checks after an official but withdrawn source exposed a gap.

  4. V3

    Monitored regulatory intelligence

    Added source monitoring and lifecycle-aware updates for the approved RBI lending corpus.

What the tests caught

The source was real. The answer was wrong.

Problem

The system retrieved an official RBI document and produced an answer grounded in that source.

Discovery

The RBI page carried an official Withdrawn watermark.

Root cause

Retrieval optimized for semantic relevance but did not yet model regulatory lifecycle validity.

Product decision

Current regulatory authority must outrank semantic similarity.

Architecture change

Lifecycle eligibility is resolved before evidence reaches answer generation.

Regression test

Withdrawn evidence may remain available historically but must not be selected as current authority.

Regression philosophy

Every repeatable failure becomes a test.

  1. Reproduce it
  2. Understand the root cause
  3. Fix the system
  4. Add a regression case
  5. Protect future changes from reintroducing it
